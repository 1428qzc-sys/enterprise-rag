# Enterprise RAG 产品常见问题（示例）

## 支持哪些文档格式？

系统支持导入 **PDF、Word（.docx）、Excel（.xlsx）、Markdown、TXT、CSV、HTML 以及网页 URL**。上传后会自动完成解析、分块、向量化与索引。

## 检索是怎么做的？

采用**混合检索**：向量语义检索负责理解语义、BM25 关键词检索负责精确命中术语与型号，二者通过 RRF（倒数秩融合）合并，并可选接入 BGE 交叉编码器重排，显著提升召回质量。

## 回答会给出出处吗？

会。每个回答都会返回**引用溯源**信息，标注命中的文档名称、页码与原文片段，答案中以 [1][2] 的形式对应引用编号，便于核实。

## 可以切换模型吗？

支持。Embedding 与 LLM 均可在 OpenAI 兼容接口、DeepSeek、本地 Ollama、本地 BGE 之间通过环境变量切换，密钥通过 .env 配置，不写入代码。

## 如何联系客户支持？

如遇问题，请发送邮件至 **support@example.com**，或在工作日拨打客服热线 400-000-0000，我们将在 1 个工作日内响应。
